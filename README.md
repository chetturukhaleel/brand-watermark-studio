# Brand Watermark Studio

A mobile-first, browser-based watermark workspace for locally processing media.

## Planned features
- Remove the visible Gemini sparkle watermark from supported user-owned images and videos.
- Add a custom logo watermark to images and videos.
- Process media locally in the browser; no upload service or paid API is required.

## Important limitations
- Targets visible watermark artifacts only; it does not remove invisible SynthID or other embedded provenance signals.
- Video export depends on browser codec support and available device memory.
- Use only media you own or have permission to edit.

The application is under construction. Features will be marked available only after they are implemented and tested.
